DashAR is a portmanteau of "Dashboard" and "AR", pronounced as such, or like [Dasher the Reindeer](https://www.youtube.com/watch?v=c9ps42Frh6Y&t=8).

If you're interested in building the DashAR system for yourself, check out the [Installation guide](./install).

If you're interested in seeing the code behind the system, check out the [DashAR System Reference](./reference).
